# Proxy Domains Plugin

## English

This plugin for **Pelican Panel** enables each Minecraft server to have a **Proxy Domain** tab where users can choose their subdomain prefix (e.g., `point-zero` to get `point-zero.pelican.dev`). It automatically synchronizes all routes to the selected **Gate Proxy** (Lite mode) or **Velocity** server in the administration panel.

Key features:
- Users configure their subdomain from their server panel
- Admins manage proxy settings and domain configuration
- Instant route updates without server restart or player disconnection
- Automatic synchronization for Gate Proxy and Velocity

---

## Français

Ce plugin pour **Pelican Panel** permet à chaque serveur Minecraft d'avoir un onglet **Domaine Proxy** où les utilisateurs peuvent choisir leur préfixe de sous-domaine (ex: `point-zero` pour obtenir `point-zero.pelican.dev`). Il synchronise automatiquement toutes les routes vers le serveur **Gate Proxy** (mode Lite) ou **Velocity** sélectionné dans le panel d'administration.

Fonctionnalités principales:
- Les utilisateurs configurent leur sous-domaine depuis leur panel serveur
- Les administrateurs gèrent les paramètres du proxy et la configuration du domaine
- Mises à jour instantanées des routes sans redémarrage serveur ni déconnexion des joueurs
- Synchronisation automatique pour Gate Proxy et Velocity
